# Juegos para Peques

Actividades educativas para niños de 4–5 años (español, inglés y francés): números, letras, escritura con lápiz, palabras, cuentos, colorear, dibujar y piano.

La app funciona en el navegador y se puede instalar como app. El progreso se guarda solo en cada dispositivo; este repositorio contiene únicamente el código.
